# AI调用提示词｜道路交通规划与工程设计规范

以下提示词面向不同项目。使用前附上项目边界、道路属性、设计阶段、测量/交通/地质数据及可依法使用的标准文本。不得把本汇编代替正式标准原文。

## 1. 全文规范检索与校核

```text
请对【项目/道路对象】进行道路交通规划与工程设计规范校核。先辨明规划层级、道路行政/技术属性、主管部门、设计阶段和地域；区分城市道路、公路、桥梁、互通、慢行与无障碍适用体系。请通过主管部门、国家标准信息公共服务平台、交通运输标准化信息系统等正式来源核实截至【日期】的标准号、版本、状态、实施/替代关系。每项结论列规范名称、编号/版次、条款号、原文适用条件、指标单位、强制/推荐属性、官方链接和核验日期。只有目录信息而无正文的标“条文待核”，不得推测数值；冲突条款逐项比较适用范围和效力，不得择大或择小。输出问题清单和需专业/主管部门确认事项，不宣称超出资料范围的全面合规。
```

## 2. 城市道路规划与工程设计

```text
请基于【规划类型、行政层级、道路类别、建设阶段、地形与交通资料】核校城市道路系统。分别检查功能分级、道路网络与用地/公交/慢行协同、横断面、道路红线、平纵线形、交叉口、无障碍、排水管线和近期实施条件。优先适用GB 55011及其配套现行标准，逐项写明条款、对象和条件；不将公路指标自动套用于城市道路。缺少交通量、设计速度、设计车辆、测量/高程或管线资料的参数标“待定/待工程核验”。不要把规范数值与课程经验值混写。
```

## 3. 高速公路及互通设计

```text
请对【高速公路/互通方案】按公路行业标准进行方案阶段审查。先确认高速公路等级、设计速度、设计交通量、枢纽/一般互通类型、接入道路属性、地形、收费与服务设施条件。核查互通间距、匝道设计速度/半径/纵坡、加减速车道、交织、出入口、主线运行、交通安全、桥梁净空及用地影响。每个参数必须引用适用JTG标准的具体条款/表和条件。平面图交叉不代表平面连通；城市道路接入和国省道接入另查审批。没有全文或工程输入时只列待核问题，不补造几何值。
```

## 4. 交叉口与三类“圆角”校核

```text
请审查【交叉口位置及设计输入】。先分别标识：①道路中心线平曲线（路线线形及设计速度控制）；②交叉口路缘石圆角（由转弯车辆、转向、速度、道路断面、行人/非机动车和公交/消防需求确定）；③道路红线边界几何倒圆（规划控制表达，不替代前两项）。列明控制方式、交角、设计车辆、扫掠轨迹、交通量、视距、渠化、过街和无障碍输入。不得用统一圆角半径或CAD FILLET值替代设计分析。缺少条文或数据时说明待核。
```

## 5. CAD道路三线绘制与面积统计

```text
请处理提供的CAD/GIS道路中心线和边界数据。先盘点坐标参考、单位、图层、对象类型和数据来源；保留原始文件。按已核实的道路设计宽度生成可编辑中心线及两侧边线，明确交叉口、桥梁和立体跨越的特殊处理；不得用线宽或填充假装边线/道路面。说明偏移和曲线构造方法、容差与软件版本，检查自交、断裂、重叠、缝隙和对象位移。几何面积按布尔并集扣重，分开统计地面道路用地、河道/交通廊道重叠和桥梁投影；该流程是技术方法，不是国家强制性规范。导出校核报告，不宣称二维几何等同法定用地或工程核验。
```

## 6. 山地城镇道路规划

```text
请对【山地城镇规划道路方案】开展规划阶段适应性与工程风险检查。结合DEM/实测高程、地质灾害、岩土、水文生态、路网和土地利用，辨明城市道路与公路属性及设计速度。审查通道连续性、纵坡与坡长、平纵组合、视距、挖填方、边坡、挡墙、排水、防灾和慢行可达。适应地形不等于放宽标准或任意增加弯曲；不得凭平面图断言纵坡、稳定性或施工可行。输出有证据的位置问题、需补充的数据和需专项论证事项。
```

## 7. 规范版本更新检查

```text
请以【核验日】更新以下标准清单：【粘贴标准号】。逐个查询主管部门正式公告、国家标准信息公共服务平台或交通运输标准化信息系统，记录标准名称、现行/废止/即将实施状态、发布和实施日期、替代关系、局部修订、强制性条文变化及适用范围。对于只有标准计划、征求意见稿、标准目录或搜索摘要的内容，明确证据级别，不等同现行正式条文。给出变更影响到的具体专题/指标编号及需要重新复核的设计成果；附可点击来源和访问日期。不得仅凭网页更新时间推断版本已替代。
```

## 8. 通用条款摘录记录模板

```text
指标编号：
指标名称：
专业：
规范名称/编号/版次：
条款/表号：
适用对象：
适用条件（道路等级、设计速度、设计车辆、地形等）：
参数数值/单位：
效力属性（强制性/推荐性/法规/技术方法）：
正式来源链接：
核验日期与核验状态：
设计注意事项/待核事项：
```

禁止将任何项目路径、项目道路编号、项目坐标或项目专属参数固化进这些提示词。
